# refs

Third-party skills on making skills, kept verbatim to take ideas from. Not published, and not bases: both
prescribe exact steps and style where [skill-creation](../../skills/skill-creation/SKILL.md) gives a smarter
reader the reasons instead. Each entry file is renamed from `SKILL.md` to `README.md`, so installers scanning
this repo don't publish it.
